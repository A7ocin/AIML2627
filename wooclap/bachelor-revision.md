# Introductory undergraduate question revision

Audience: a bachelor course providing students' first introduction to AI and ML. All 92 prompts were reviewed and rewritten; the course still has 68 core questions and 24 optional questions.

Before-topic questions invite a prediction using a familiar situation or an idea already explained in this course. They do not ask students to recall the definition that the next slide is about to teach. Mathematical questions use only one short step, with the operation stated or already explained. Checks after a topic test its main idea rather than rare edge cases or formal guarantees. Optional questions extend or revisit the basics. Exit questions ask for one short takeaway in the student's own words.

## Examples

| Lecture | Previous demand | Revised approach |
|---|---|---|
| History | Compare posterior probabilities given a likelihood ratio | Update a weather expectation after seeing dark clouds |
| Search | Compare greedy search and A* scores before the A* explanation | Add cost so far and estimated remaining cost |
| Constraints | Infer how an exponential acceptance probability changes | Consider why a temporarily worse timetable change might help |
| Introduction to ML | Recall data-scaler fitting rules before leakage | Compare a fair fresh test with a memorized practice sheet |
| Regression | Interpret negative held-out R² or residual degrees of freedom | Read a fit score on the same data and interpret slope |
| Classification | Explain nonexistent finite estimates under perfect separation | Choose which prediction gives the true class more probability |
| Perceptrons and SVMs | Recall dual constraints and positive semidefinite matrices | Explain support vectors and why flexibility needs validation |
| Clustering and PCA | Calculate mixture responsibilities or diagnose linkage inversions | Explain soft group membership and similarity in a clustering tree |

## Placement adjustments

- L05-C04 now follows the independence explanation; it no longer tests an unintroduced Naive Bayes assumption.
- L04-O01 follows the straight-line model and checks slope meaning.
- L04-O03 follows multiple regression and checks the role of several input features.
- L07-C09 follows feature scaling and checks why units affect distances.

Stable question IDs, event URLs, question types and correct-choice positions are preserved. The instructor guide, PDF, workbooks, slide prompts and live questions use the same revised bank. Keeping correct-choice positions prevents an old selection marker from accidentally becoming a different answer during the live update; the live editor is still checked explicitly.

Use 60–120 seconds as a planning estimate, including a short explanation. These are not automatic Wooclap timers. If students are uncertain before a topic, use their answers to start the explanation. Do not treat a wrong initial guess as a failure to study material they have not yet been taught.
