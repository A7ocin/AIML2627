04 · Semi-supervised learning / 4.1 · Prediction goals
1 · Learning2 · Supervised3 · Unsupervised4 · Semi-supervised5 · Reinforcement6 · Applications

Two goals: label this batch, or label future photos

Start with 100 labeled photos and 10,000 unlabeled photos.

Transductive learning

These 10,000 photos→Labels for this batch

The objective of the learning is to classify the unlabeled data only, without the necessity of generalizing over unseen data.

Inductive learning

Learn a classifier→Label tomorrow’s photos

The objective is to teach the model to label also unobserved data.

Semi-supervised describes the training data. Transductive and inductive describe which cases we want to predict.
Handout explanation ↗Link to this slide
Transduction targets the particular unlabeled batch supplied now. Induction learns a function to apply to new inputs beyond that batch. Induction is not defined as also labeling the batch. Both goals can use a labeled/unlabeled mixture. These are goals, not guarantees that a method has succeeded.

05 · Reinforcement learning / 5.2 · Bandit setup
1 · Learning2 · Supervised3 · Unsupervised4 · Semi-supervised5 · Reinforcement6 · Applications

What is a bandit arm?

A bandit problem: repeatedly choose an action and observe its uncertain reward.

One round

1. Choose an arm: select action A, B or C.

2. Observe its reward: in our example, 1 or 0.

3. Update its estimate: use what that choice taught you.

An arm is an action; a pull is choosing it once. The name comes from a slot-machine lever.

You see only the chosen arm’s reward. The same arm can give 1 now and 0 next time. The goal is to maximize total reward across many rounds.
Handout explanation ↗Link to this slide
The slot-machine picture explains the terminology, not a gambling activity. In the demonstration, each arm has a fixed but unknown probability of reward 1. Outcomes vary from pull to pull. Only the chosen outcome is observed. The learner estimates each rate from its own observations and balances immediate reward against information. Unlike chess, this bandit has no changing board state.
05 · Reinforcement learning / 5.3 · Bandit example
1 · Learning2 · Supervised3 · Unsupervised4 · Semi-supervised5 · Reinforcement6 · Applications

Explore or exploit? Try three uncertain actions

Each arm is an action with an unknown reward chance; n counts how many times that arm was pulled.

Added stationary three-armed Bernoulli bandit with reward probabilities 0.25, 0.50 and 0.75. It is a simple reinforcement-learning setting without state transitions or delayed rewards. Each arm is tried once before automated epsilon-greedy selection. Ties use seeded randomness. The finite run need not identify the best arm.
