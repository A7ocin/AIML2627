𝒩5(xi)={0,1,1,0,1}

KNN classifies an input with the majority class among its K nearest neighbors. For every candidate class c, sum an indicator over the target entries yⱼ in 𝒩ₖ(xᵢ). Each matching label contributes one, and each other label contributes zero. The sum is the class vote count. The argmax selects the candidate with the largest count and returns its label. For {0,1,1,0,1}, class 1 receives three votes versus two for class 0. The prediction is therefore ŷᵢ=1. The method depends on the stored data, a chosen K, and the neighborhood determined by a mathematical metric. There are no coefficients learned by this vote formula. Here j indexes a selected training observation, rather than a feature column.

A small coordinate example

Euclidean distance is one choice. Feature units affect which inputs count as close.
xᵢ = query input, xⱼ = stored training inputxᵢ₁,xᵢ₂ = the two query feature valuesxⱼ₁,xⱼ₂ = the corresponding stored feature values‖xᵢ−xⱼ‖₂ = Euclidean distance between the inputs
The neighborhood can be constructed with a mathematical metric. Here we use Euclidean distance ‖xᵢ−xⱼ‖₂, the straight-line distance between two inputs. For the two-dimensional example it is the square root of the sum of the two squared feature differences. 5.7.1 · Bayesian derivation

From neighbor votes to class probabilities

With one vote per neighbor, the vote share from the previous example estimates the probability of a class for the new input.

ℙ(Y=c∣X=x)≈KcKBayes decision rule:y^=argmaxc∈𝒴 ℙ(Y=c∣X=x)
Three of five neighbors in class 1 give an estimate of 3/5 = 0.60.
Predict the class with the largest fraction.
K = number of selected neighborsK꜀ = neighbors in class c𝒴 = set of class labels
Although the KNN vote formula directly returns a class label, it also has a probabilistic interpretation. The fraction K꜀/K estimates ℙ(Y=c | X=x), where K꜀ counts the selected neighbors belonging to class c. The class with the largest count also has the largest fraction because K is common to all classes. We use ≈ to distinguish a finite-sample estimate from the unknown true class probability. To motivate it, return to Bayes’ theorem: posterior equals class-conditional likelihood times prior divided by input density. The following steps estimate those three quantities locally. ℙ states a probability event in full. Lowercase p names a distribution function, as in Part 1. Because Y is discrete, pᵧ|ₓ(y | x)=ℙ(Y=y | X=x). With continuous inputs, pₓ and pₓ|ᵧ are densities, rather than point probabilities.
5.7.1 · Bayesian derivation

Start with Bayes’ theorem

pY∣X(y∣x)=pX∣Y(x∣y)pY(y)pX(x)
Class posterior=Likelihood×Class priorEvidence

Estimate these three quantities

Likelihood, prior, and evidence.

Use a region around x

We begin with the input density and estimate it from nearby data.

pY∣X(y ∣ x) = posterior class probabilitypX∣Y(x ∣ y) = likelihood (class-conditional density)pY(y) = prior (class probability before observing x)pX(x) = evidence (input density)
Use y for a generic class value and c for a specific candidate class. For continuous inputs, the class-conditional and input terms are densities.
5.7.1 · Bayesian derivation

Estimating the evidence from a small region

Bayes’ theorem needs the input density at the query, which we can approximate using the probability mass around it.

Pℛ=ℙ(X∈ℛ)=∫ℛpX(x)dx

The integral adds up the density across 𝓡 to give the shaded area.

pX(x)≈PℛV
If density is nearly constant in the region, probability mass ≈ density × volume.
𝓡 = region around the query xX = random inputpX = input densityPℛ = probability mass in 𝓡ℙ = probabilityV = size of the input region 𝓡With one input coordinate, V is length. With two input coordinates, V is area. With three input coordinates, V is volume.
Begin with the input density pₓ(x). Consider a small region 𝓡 centered around the query. V measures the input region itself. In the plot, that is the width of the interval along the input axis. The region’s probability mass Pᵣ=ℙ(X∈𝓡) is the integral of pₓ over the region. In that integral, x is the variable that runs over possible input values. If the density changes little across this small region, probability mass is approximately density times volume. Rearranging gives pₓ(x)≈Pᵣ/V. We cannot evaluate the integral directly because the true input distribution is unknown. The next argument uses the fraction of sampled observations falling inside the region to estimate Pᵣ.

5.7.1 · Bayesian derivation

Why does the neighbor vote estimate a probability?

We want to estimate the chance that a new input belongs to a class. Bayes’ theorem gives us a way to do this, using quantities we can estimate from the training data.

Count inside the region

First, show why the fraction of training inputs inside a fixed region estimates the probability of landing there.

Estimate the three Bayes terms

Evidence is the local density across all inputs.
Likelihood is the local density within the chosen class.
Prior is the class’s overall frequency.

See what cancels

Put those estimates into Bayes’ theorem. The shared region size cancels, along with the dataset counts, leaving a fraction of the neighbors.

The formula we’ll deriveℙ(Y=c∣X=x)≈KcKFor query x, K is the total number of selected neighbors and Kc counts those in class c.
First hold a region fixed to explain why an observed fraction estimates its probability mass. Then apply the idea to the common region containing the selected neighbors. Use all the training inputs for the evidence, only inputs of the candidate class for the likelihood, and the overall class frequency for the prior. The same region size appears in both density estimates.
5.7.1 · Bayesian derivation

Why can a count estimate the region’s probability?

01 · Count inside a fixed region

K~Bin(n,Pℛ)

02 · Find the expected count

𝔼[K]=nPℛ

03 · Divide by the sample size

𝔼[Kn]=𝔼[K]n=Pℛ

04 · Measure the spread

Var[Kn]=Var[K]n2=nPℛ(1−Pℛ)n2=Pℛ(1−Pℛ)n

05 · Estimate the probability

Kn≈𝔼[Kn]=Pℛ
𝓡 is fixed in this counting argumentK = random count inside 𝓡, n = sampled inputsPℛ = probability that one input lies inside 𝓡Bin = binomial distribution𝔼 = expectation, Var = varianceIn KNN itself, K is chosen and the region changes to include K neighbors.
Hold the region 𝓡 fixed. Each independent observation either falls inside it or outside it. K counts how many of the n observations fall inside. Its possible values are 0,…,n. This is a binomial count, with probability Pᵣ of an inside outcome. An individual observation has probability Pᵣ of falling inside. Across n observations, the expected number inside is n times that probability. For example, if n=100 and Pᵣ=0.20, the expected count is 20. K/n is the observed fraction inside the region. Divide the expected count nPᵣ by the fixed number n. The n factors cancel. The expected fraction is therefore the true probability mass Pᵣ. Step 4 measures the spread of K/n across repeated samples. With the region fixed, the spread shrinks as the sample grows. Step 5 uses K/n from one sample as the estimate. Step 3 gives its center and step 4 explains why it tends to stay close to that center in large samples.

The local density is approximately probability mass divided by volume (as in the previous slides). Replace the unknown mass Pᵣ with the observed fraction K/n. Dividing K/n by V gives the density estimate K/(nV). Now look only at the n꜀ training observations belonging to class c. Of those, K꜀ fall in the same local region. Its class-conditional fraction is K꜀/n꜀. Divide by the same volume V to estimate the feature density within that class. The class prior describes how common class c is before the query is considered. Estimate it by the fraction of all training observations with that label. Here n꜀ counts the class in the whole dataset, whereas K꜀ counts it locally. Use posterior = likelihood × prior / input density. The likelihood estimate is K꜀/(n꜀V), the prior estimate is n꜀/n, and the input-density estimate is K/(nV). All three refer to the same query and local region. First, n꜀ cancels in likelihood × prior, leaving K꜀/(nV). Then the common factor 1/(nV) cancels between numerator and denominator. Only the local fraction K꜀/K remains. It estimates the conditional class probability.

From the circle’s counts to a class probability

Choose K, move the query and choose a class. Use the same circle to estimate both densities, then substitute the numbers into Bayes’ theorem.

The circle is centered on the query and extends to the K-th nearest input. It contains the selected K neighbors. Choose which class c to inspect. The class prior is n꜀/n. The table substitutes the actual counts and area into these expressions. Bayes’ theorem combines them as class density × prior / input density. Since both densities refer to the same circle, the factors n꜀ and 1/(nV) cancel, leaving K꜀/K. The equality is exact for these estimates, while their relationship to the unknown population posterior is approximate. Changing K or moving the query changes the radius, area and counts. You can also switch the inspected class between 0 and 1. Density heights can exceed one because they are mass per unit of area. The final normalized class probability remains between zero and one. All calculations use unrounded values.
5.7.2 · K-NN regressor

From voting to averaging

The same nearest neighbors can predict a number by averaging their target values.

y^i=1K∑yj∈𝒩K(xi)yj

Find the K nearest inputs

Use their numerical targets.

Average those targets

𝒩3(xi)={2,6,10}
y^i=2+6+103=6
ŷᵢ = predicted numerical target𝒩K(xi) = collection of selected targetsyⱼ = one selected target
KNN can also predict a quantitative outcome. Neighborhood selection works in the same way, but the selected targets are numbers. Instead of counting votes for classes, sum those target values and divide by K. For three targets 2,6,10, the prediction is (2+6+10)/3=6. Thus the KNN regressor estimates the new outcome as the average of the K nearest observations’ target values.

5.7.3 · Validation

What happens when we average every target?

In the regression demo, setting K = n makes every query average the same training targets.

y^i=1n∑xj∈𝒟yj=y¯

Regression predicts the global mean. Classification predicts the global majority class.

n = number of stored observationsȳ = global mean of the targetsEqual weights give a constant prediction, which can have high bias.𝒟 = training dataset
With equal weights and K = n, every training observation contributes. The classifier uses the most represented class. The regressor returns the global mean, equivalent to a constant regression model of order zero. This endpoint has low flexibility and can have high bias.
5.7.3 · Validation

What happens when we use just one neighbor?

At the other extreme, K = 1 makes the prediction depend entirely on the closest stored observation.

y^i=yi*

A different sample can change the nearest target. This highly local rule typically has higher variance.

i∗ = index of the closest stored observationyi∗ = its observed target
Validation helps choose a value of K between these extremes.
At K = 1, both classification and regression copy the target of the nearest training observation. A different sample can change which observation is nearest and therefore change the prediction. This is the high-variance end of the bias–variance trade-off.
5.7.3 · Validation

How do we choose K between these extremes?

The last two slides show how K changes the prediction, so we need a fair way to compare candidate values.

The tempting approach

Try several values of K and keep the one with the best test score.

Use validation to choose K

Choosing K selects a prediction rule. Compare candidates on validation data and reserve test data for the final assessment.

K is a hyperparameter chosen by comparing candidate models.
It may seem natural to compare several K values on the test set and choose the best one. That contains a fallacy. Although K is not estimated by the ordinary KNN training rule, selecting it from outcomes still selects a prediction hypothesis. It can therefore influence generalization in the same way as other model fitting choices. K is called a hyperparameter, and its selection procedure is called validation. Data used repeatedly to choose K are validation data in practice, whatever they were originally named. A final test set must remain outside that selection. For numerical targets one can compare RMSE values. For class labels one can compare classification accuracy. The important point is that all candidates use validation observations, not the observations reserved for the final report.

Store the training examples.

The correct procedure separates observations into training, validation and test sets. For each candidate hyperparameter configuration, construct the model from training data and evaluate it on validation data. Select the best model according to validation performance, then report the selected model’s performance on the test set. In practice, a portion of the available training data is often reserved for validation. After achieving good validation performance, the final test checks whether that performance generalizes. Training supports the model, validation supports selection, and test supports final evaluation.

Validation applies to KNN classification and regression. For labels, accuracy counts correct predictions, as in Part 1. 5.7.4 · Characteristics

When might KNN be a useful choice?

A useful relationship has a known form

A parametric model can work well when its chosen form fits the relationship.

We want a more flexible shape

KNN uses local examples and can adapt to varied decision boundaries or regression shapes.

KNN has the advantage of being nonparametric and versatile: it does not restrict the relationship to a particular parameterized shape. A parametric model is limited by its initial form assumption. If the true relationship is well described by that parametric form, a parametric model may be preferable. KNN’s flexibility also brings memory and prediction-time costs, considered next.

Memory is a main weakness of KNN. Its stored model depends on the dataset size. Increasing local data coverage can require keeping more observations, which takes space. A parametric model stores information from the training data in a compact parameter vector instead. Prediction time is another weakness. To find a new observation’s nearest neighbors, a straightforward procedure may scan the whole dataset each time. Stored distance information and tree-based search structures can speed up suitable searches, but storage itself also has a cost.
