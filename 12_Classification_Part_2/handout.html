5.7 · K-Nearest NeighborsParametric and nonparametric models

Parametric · Logistic regression

Choose a model form with a fixed number of coefficients.

Fit the coefficients on training data. For a new input, evaluate the fitted formula.

Nonparametric · KNN

Keep the labelled training examples.

For a new input, find its nearest examples and let their labels vote. As the dataset grows, KNN can represent more detailed decision boundaries.

K is a hyperparameter. It sets how many neighbors vote. It is chosen during model selection.

For a given set of features, logistic regression uses an intercept and one coefficient per feature. Adding more training observations can change their fitted values. In KNN, the stored examples determine the prediction locally, so the set of points that can shape the decision boundary grows with the training set. K controls the size of the neighborhood.

5.7 · K-Nearest NeighborsK-Nearest Neighbors

Store the observations

Keep the training inputs and their labels.

Predict from nearby examples

Find the K nearest inputs. Their labels vote.

KNN is nonparametric. It uses the stored observations to predict.
K = chosen neighbor countTraining data 𝒟={(xi,yi)}i=1nn = number of training observations

The K-Nearest Neighbors classifier keeps the labelled training observations and uses nearby inputs at prediction time. The neighbor count K is chosen outside training. The method can adapt to a wide range of decision boundaries, with memory and prediction-time costs discussed in Characteristics.

K-Nearest Neighbors, abbreviated KNN or K-NN, is nonparametric. It does not fit a fixed coefficient vector for a predefined global relationship. It keeps the observations and predicts from nearby inputs. K is a chosen number of neighbors rather than a coefficient fitted by the learning rule. The method can adapt to varied relationships, but its flexibility has limitations that we examine later.

5.7.1 · Bayesian derivationFrom neighbor votes to class probabilities

With one vote per neighbor, the vote share from the previous example estimates the probability of a class for the new input.

ℙ(Y=c∣X=x)≈KcKBayes decision rule:y^=argmaxc∈𝒴 ℙ(Y=c∣X=x)
Three of five neighbors in class 1 give an estimate of 3/5 = 0.60.
Predict the class with the largest fraction.
K = number of selected neighborsK꜀ = neighbors in class c𝒴 = set of class labels

Although the KNN vote formula directly returns a class label, it also has a probabilistic interpretation. The fraction K꜀/K estimates ℙ(Y=c | X=x), where K꜀ counts the selected neighbors belonging to class c. The class with the largest count also has the largest fraction because K is common to all classes.

We use ≈ to distinguish a finite-sample estimate from the unknown true class probability. To motivate it, return to Bayes’ theorem: posterior equals class-conditional likelihood times prior divided by input density. The following steps estimate those three quantities locally.

ℙ states a probability event in full. Lowercase p names a distribution function, as in Part 1. Because Y is discrete, pY∣X(y | x)=ℙ(Y=y | X=x). With continuous inputs, pX and pX∣Y are densities, rather than point probabilities.

5.7.1 · Bayesian derivationEstimating the evidence from a small region

Bayes’ theorem needs the input density at the query, which we can approximate using the probability mass around it.

Pℛ=ℙ(X∈ℛ)=∫ℛpX(x)dx

The integral adds up the density across 𝓡 to give the shaded area.

pX(x)≈PℛV
If density is nearly constant in the region, probability mass ≈ density × volume.
𝓡 = region around the query xX = random inputpX = input densityPℛ = probability mass in 𝓡ℙ = probabilityV = size of the input region 𝓡With one input coordinate, V is length. With two input coordinates, V is area. With three input coordinates, V is volume.

Begin with the input density pX(x). Consider a small region 𝓡 centered around the query. In the plot, V is the width of the interval along the input axis, and the shaded area is the probability mass.

The region’s probability mass Pℛ=ℙ(X∈𝓡) is the integral of pX over the region. In that integral, x is the variable that runs over possible input values. If the density changes little across this small region, probability mass is approximately density times volume. Rearranging gives pX(x)≈Pℛ/V.

We cannot evaluate the integral directly because the true input distribution is unknown. The next argument uses the fraction of sampled observations falling inside the region to estimate Pℛ.

We want to estimate the chance that a new input belongs to a class. Bayes’ theorem gives us a way to do this, using quantities we can estimate from the training data.

Count inside the region

Estimate the three Bayes terms

Evidence is the local density across all inputs.
Likelihood is the local density within the chosen class.
Prior is the class’s overall frequency.

See what cancels

The formula we’ll deriveℙ(Y=c∣X=x)≈KcKFor query x, K is the total number of selected neighbors and Kc counts those in class c.

5.7.1 · Bayesian derivationWhy can a count estimate the region’s probability?

01 · Count inside a fixed region

K~Bin(n,Pℛ)

Hold the region 𝓡 fixed. Each independent observation either falls inside it or outside it.

K counts how many of the n observations fall inside. Its possible values are 0,…,n.

This is a binomial count, with probability Pℛ of an inside outcome.

Teaching example: n=100 independent inputs and PR=0.20. The count K changes from sample to sample.

02 · Find the expected count

𝔼[K]=nPℛ

An individual observation has probability Pℛ of falling inside.

Across n observations, the expected number inside is n times that probability.

For example, if n=100 and Pℛ=0.20, the expected count is 20.

Example: 100×0.20=20 expected points inside the fixed region.

03 · Divide by the sample size

𝔼[Kn]=𝔼[K]n=Pℛ

K/n is the observed fraction inside the region.

Divide the expected count nPℛ by the fixed number n. The n factors cancel.

The expected fraction is therefore the true probability mass Pℛ.

Example: 𝔼[K/100]=20/100=0.20. This is an average over repeated samples.

04 · Measure the spread

Var[Kn]=Var[K]n2=nPℛ(1−Pℛ)n2=Pℛ(1−Pℛ)n

Step 3 gave the average across samples. How far might one sample’s K/n be from that average?

To measure that spread, start with the binomial variance Var(K) = nPℛ(1 − Pℛ).

Dividing K by n divides its variance by n². The variance of K/n shrinks as n grows.

Example: 0.20×0.80/100=0.0016. With n=1000 the variance is 0.00016.

05 · Estimate the probability

Kn≈𝔼[Kn]=Pℛ

Step 3 tells us where K/n is centered. Its average is the true probability mass Pℛ.

Step 4 tells us how tightly K/n clusters around that average. Larger samples have smaller variance.

With enough independent observations, one sample’s K/n is therefore likely to be close to Pℛ.

For example, an observed K=18 gives 18/100=0.18 as an estimate of the unknown probability mass.

𝓡 is fixed in this counting argumentK = random count inside 𝓡, n = sampled inputsPℛ = probability that one input lies inside 𝓡Bin = binomial distribution𝔼 = expectation, Var = varianceIn KNN itself, K is chosen and the region changes to include K neighbors.

5.7.1 · Bayesian derivationFrom the circle’s counts to a class probability

Choose K, move the query and choose a class. Use the same circle to estimate both densities, then substitute the numbers into Bayes’ theorem.

The circle is centered on the query and extends to the K-th nearest input. It contains the selected K neighbors. Choose which class c to inspect. K꜀ counts that class inside the circle, while n꜀ counts it in the whole training dataset. Here n=50 and each class has n꜀=25.

Select the same kind of neighborhood

Find the K nearest training inputs to xᵢ.
Their target values are now numbers, rather than class labels.

Add the targets, then divide by K

𝒩3(xi)={2,6,10}
y^i=2+6+103=6
Classification uses the majority label.
Regression uses the average numerical target.

For three targets 2,6,10, the prediction is (2+6+10)/3=6. Thus the KNN regressor estimates the new outcome as the average of the K nearest observations’ target values.

5.7.3 · ValidationWhat happens when we average every target?

In the regression demo, setting K = n makes every query average the same training targets.

y^i=1n∑xj∈𝒟yj=y¯

Regression predicts the global mean. Classification predicts the global majority class.

n = number of stored observationsȳ = global mean of the targetsEqual weights give a constant prediction, which can have high bias.𝒟 = training dataset

With equal weights and K = n, every training observation contributes. The classifier uses the most represented class. The regressor returns the global mean, equivalent to a constant regression model of order zero. This endpoint has low flexibility and can have high bias.

With K=n and equal weights, every training observation contributes. Classification always chooses the most represented class. Regression always returns the global target mean, equivalent to a constant regression model of order zero. This is the least flexible endpoint and can have high bias.

With K=1, the prediction is the target of the single nearest observation. A new training sample can change that observation and its target, making predictions variable across datasets. This endpoint therefore has high variance. The bias–variance pattern is a general tendency, rather than a guarantee of monotonic improvement for every dataset.

At the other extreme, K = 1 makes the prediction depend entirely on the closest stored observation.

5.7.3 · ValidationHow do we choose K between these extremes?

The last two slides show how K changes the prediction, so we need a fair way to compare candidate values.

A tempting comparison

Try several K values.
Check each one on the test set.
Keep whichever test result looks best.

The problem

We have used those outcomes to choose the predictor.
The “test” data have become part of model selection, so the result is no longer an independent final assessment.

K is a hyperparameter: a setting selected outside the model’s ordinary training rule.
Validation is the procedure used to choose it. Selecting K still chooses a hypothesis from the hypothesis space.
K = candidate neighbor countHyperparameter = a setting chosen by comparing candidate modelsValidation set = observations used for that comparisonTest set = observations reserved for assessing the selected modelHypothesis space = set of candidate prediction rules

It may seem natural to compare several K values on the test set and choose the best one. That contains a fallacy. Although K is not estimated by the ordinary KNN training rule, selecting it from outcomes still selects a prediction hypothesis. It can therefore influence generalization in the same way as other model fitting choices.

K is called a hyperparameter, and its selection procedure is called validation. Data used repeatedly to choose K are validation data in practice, whatever they were originally named. A final test set must remain outside that selection.

For numerical targets one can compare RMSE values. For class labels one can compare classification accuracy. The important point is that all candidates use validation observations, not the observations reserved for the final report.

5.7.3 · ValidationThree datasets separate fitting, choosing and assessing

Training: 30 cases
Validation: 10 cases
Test: 10 cases

Training

Use these observations to construct each candidate predictor.
For KNN, keep the training input–target pairs.

Validation

Compare the candidate K values on these observations.
Choose the best validation result.

Test

Once K is fixed, assess the chosen model here.
Report this result as the final performance estimate.

  1. For each K, construct the predictor and evaluate it on validation data.
  2. Select the K with the best validation performance.
  3. Report that selected predictor’s performance on the test set.
Often, we reserve part of the available training data for validation.
Good validation performance should also hold on the final test observations if the procedure generalizes.

The correct procedure separates observations into training, validation and test sets. For each candidate hyperparameter configuration, construct the model from training data and evaluate it on validation data. Select the best model according to validation performance, then report the selected model’s performance on the test set.

In practice, a portion of the available training data is often reserved for validation. After achieving good validation performance, the final test checks whether that performance generalizes. Training supports the model, validation supports selection, and test supports final evaluation.

Validation applies to KNN classification and regression. For labels, accuracy counts correct predictions, as in Part 1. For numerical targets, RMSE averages the squared prediction errors and takes a square root, as introduced in regression. These are familiar metrics used here to clarify which comparison belongs to which target type.

In these evaluation formulas, n counts the cases being evaluated and i indexes them. It does not count selected neighbors. Compare all candidate K values on the same validation cases. After selecting K, evaluate the fixed predictor on test cases for the final report.

5.7.3 · ValidationChoose K using validation, then reveal the test

Compare K = 1, 5 and 15. Click a validation case to see how its neighbors voted, then lock your choice to reveal the test score.

This example uses 35 synthetic observations with one input score and a known class, 0 or 1. Each candidate uses the same 15 training observations to predict the same 10 validation cases. Another 10 cases are reserved for the test. Nearest means the smallest absolute difference between input scores.

Start with the validation case at input score 35. Its actual class is 0. With K = 1, the nearest training score is 34 and its class is 1, so the prediction is wrong. With K = 5, four of the five neighbors vote for class 0 and the prediction is correct. Select another case to inspect its votes.

K = 1 gets 8 of 10 validation cases right, K = 5 gets 9 of 10, and K = 15 gets 5 of 10. With K = 15, every query sees the same training majority of class 0. Choose K = 5 using validation, then lock it to reveal 8 of 10 correct on the separate test cases. Use the test score to report final performance.

5.7.4 · CharacteristicsWhen might KNN be a useful choice?

A useful relationship has a known form

A parametric model builds that form into its formula.
If the assumption fits the true relationship, a compact parametric model can be preferable.

We want a more flexible shape

KNN does not commit to that fixed parameterized form.
Local examples can describe varied decision regions or numerical relationships.

The flexibility of KNN is an advantage, but it requires stored observations and work for each new prediction.
The next slide compares those costs with a compact parametric model.

KNN has the advantage of being nonparametric and versatile: it does not restrict the relationship to a particular parameterized shape. A parametric model is limited by its initial form assumption.

If the true relationship is well described by that parametric form, a parametric model may be preferable. KNN’s flexibility also brings memory and prediction-time costs, considered next.

5.7.4 · CharacteristicsKNN stores more data and does more work at prediction time

Memory requirements

KNN keeps the training observations.
More stored examples require more space.
A parametric model instead compresses information into its fitted parameters.

Computation for a new input

Finding neighbors may require checking the whole training dataset for each query.
A large dataset can make this slow.

Stored distance information or clever search trees can speed up neighbor search.
These approaches also have storage costs. The central trade-off is memory and prediction time.

Memory is a main weakness of KNN. Its stored model depends on the dataset size. Increasing local data coverage can require keeping more observations, which takes space. A parametric model stores information from the training data in a compact parameter vector instead.

Prediction time is another weakness. To find a new observation’s nearest neighbors, a straightforward procedure may scan the whole dataset each time. Stored distance information and tree-based search structures can speed up suitable searches, but storage itself also has a cost.
