# Shared course resources

These folders support the 16 lecture packs linked from `../index.html`.
They replace the old unsplit lecture folders; they are not lecture entry points.

| Resources | Active lecture packs |
| --- | --- |
| `history` | 01–02: History |
| `search` | 03–04: Search |
| `constraints` | 05–06: Constraints |
| `intro-ml` | 07–08: Introduction to ML |
| `regression` | 09–10: Regression |
| `classification` | 11–12: Classification |
| `classification-2` | 13–14: Classification |
| `clustering` | 15–16: Clustering |

Preserve these resources when distributing the course. The subject folders also
retain source notes, numerical tests, data-generation tools and previous review
artifacts. Subject README files and whole-deck build/review scripts describe the
original unsplit material; edit the active lecture HTML for current slide content.
The supported PDF builder is `../_tools/build-slide-pdfs.cjs`.
