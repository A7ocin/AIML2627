Bridge from Part 1Now make the prediction task precise

A predictor is an input used to make a prediction; the outcome or target is what we want to predict. For the crop-yield task, fertilizer level is the predictor and crop yield is the outcome. These roles will be used before introducing their mathematical notation.

Part 1 compared learning settings and application domains. Here we focus on one chosen task: supervised regression for crop yield. The shared example provides continuity; the new material explains how to record observations, define candidate functions and assess predictions.

We will not reclassify the learning settings. Instead, we move from an informal task to a dataset, a prediction function, a model family and a procedure for evaluating new cases.

A variable is a feature recorded across experiments when possible. Examples include age, number of owned cars, hair colour and recorded sex categories. The table explains the variable types and gives examples of each.

1.4Predictors are inputs; the outcome is the target

This formulation predicts one outcome Y from one or more predictors X₁, …, Xₘ; m is their number. A predictor is an input variable, also called a feature, independent variable or explanatory variable. The outcome is the output to predict, also called target, dependent/predicted variable or response.

These names describe task roles and may refer to a variable or its recorded measurement in context. “Independent” does not establish statistical independence, and “explanatory” does not establish causation. A proposed predictor may turn out to have no useful relationship with the outcome.

Inputs must be available at prediction time. Soil moisture measured before planting could be used to predict yield. Future realized rainfall would not be available for a prediction made beforehand; a forecast is a different input.

1.6Domains contain values; input spaces contain combinations

The domain 𝓧ⱼ is the set of values allowed for predictor Xⱼ. The outcome domain is 𝓨. For quantitative regression, 𝓨 is typically a subset of the real numbers ℝ; for classification it is a finite set of class labels.

The full input space is the Cartesian product 𝓧 = 𝓧₁ × ··· × 𝓧ₘ. Here × means that we form tuples by choosing one value from each domain; it is not multiplication of measured values. With fertilizer and soil moisture as predictors, one input is a pair consisting of one fertilizer value and one moisture value.

The notation x ∈ 𝓧 means that x belongs to the input space. A space describes possible cases; a dataset contains only the particular cases we recorded. A suitable encoding is needed before categorical, image or text inputs can be used in a numerical design matrix.

In the diagram, three allowed fertilizer values and three moisture values give 3 × 3 = 9 possible input pairs. The three recorded toy observations occupy only three of those combinations.

For an illustrative two-predictor example, let x₁ = (0.2, 0.4)ᵀ and y₁ = 0.8. The first input entry is fertilizer level and the second is soil moisture; the target is yield. These toy values illustrate vector and matrix notation. They are separate from the 25-observation fertilizer plot, which has only one predictor.

2.2Training fits predictions to recorded targets

Plotting the collected measurements reveals a possible curved relationship. Model training searches for a convincing prediction function that fits those recorded pairs. The assumed model restricts its possible form, such as a polynomial family. Model can also mean the fitted function after training.

A function f: 𝓧 → 𝓨 maps an input xᵢ to a prediction ŷᵢ = f(xᵢ). Its prediction should be approximately equal to the corresponding measured target yᵢ for recorded pairs (xᵢ,yᵢ) in the dataset 𝓓. The hat marks a prediction, ∈ means belongs to, and ≈ means approximately equal. The complete fitting equation is shown below.

The task is regression because the outcome is a quantitative magnitude. Approximate fit is expected: measurements need not lie exactly on one curve. The next step fixes a function form and identifies the parameters that training can change.

2.3A model fixes a form; a hypothesis chooses its parameters

Following the course convention, a model is an assumed function form. Once that form is fixed, a hypothesis θ is one numerical parameter setting, and the hypothesis space Θ is the set of allowed settings. The corresponding prediction rule is written fθ; the parameters need the assumed form to determine that function.

For the illustrative family fθ(x) = ax² + bx + c, θ = (a,b,c). Here x is one numerical input, a multiplies the squared term, b multiplies the linear term, and c is the intercept: the prediction at x = 0. The three curves illustrate three different coefficient choices in the same family.

Training changes coefficients within the selected form. Choosing another maximum polynomial degree changes the model family. Because Θ = ℝ³ permits a = 0, the displayed family contains polynomials of degree at most two, including linear and constant special cases.

The course’s supplied example curve is explored separately. Its model family and fitting algorithm are not specified, so it is not asserted to be quadratic or an optimal fit.

2.4A hypothesis space contains the allowed choices

The parameter setting θ selects one candidate function. The hypothesis space Θ is the set of allowed parameter settings, following the parameter-based convention used in the course. In the unrestricted quadratic example, Θ = ℝ³: every triple (a, b, c) of real coefficients is allowed.

For θ = (1, 0, 0), the selected function is fθ(x) = x². For θ = (2, −1, 0.5), it is fθ(x) = 2x² − x + 0.5. Both choices belong to the same space Θ and use the same functional form.

Another common convention calls the functions themselves hypotheses and calls their set the hypothesis space. Here θ names the coefficients and fθ names the corresponding function, so the distinction stays explicit. Fitting chooses a θ; model selection can compare families or complexity settings.

3.1Compare the observations and hypothesis

3.2Why does the curve miss some observed points?

3.3A residual is the gap between observation and prediction

The prediction for observation i is ŷᵢ = fθ(xᵢ). Its residual is rᵢ = yᵢ − ŷᵢ, the observed target minus the prediction. A positive residual means the model predicted too low; a negative one means it predicted too high.

Mean squared error (MSE) averages the squared residuals over n observations: MSE=1n∑i=1n(yi−ŷi)2. The summation symbol ∑ means add the terms for i = 1 through n. Squaring prevents positive and negative residuals from cancelling and gives larger disagreements more weight.

MSE is one concrete score for regression, used here as a bridge to the regression lecture. Its units are squared target units. A lower training MSE means a closer fit to these recorded targets, not necessarily more accurate predictions on new cases.

3.4Generalization means predicting relevant new cases

A prediction function should work beyond the recorded pairs in 𝓓, on relevant unseen cases in the input and outcome domains. Generalization means predicting the outcome of relevant unseen inputs, rather than only explaining the measurements used to fit the function.

In the displayed new-case formula, x is an input and y is its associated outcome; ŷ = fθ(x) is the fitted rule’s prediction. The pair belongs to 𝓧 × 𝓨 because these are its input and outcome domains. This membership specifies the possible types of pairs. It does not require fitting every arbitrary pairing of an input with an unrelated outcome.

With noisy outcomes, approximate agreement on useful new cases is the aim. A small training error is not sufficient evidence of this. Held-out observations estimate performance for the intended future use; the following practical sections separate fitting, model choice and final assessment.

3.5Training, validation and test sets have different jobs

A training set is used to fit model parameters and any learned preprocessing. A validation set is held out from that fitting step and used to compare development choices, such as polynomial degree. A test set is reserved for estimating performance after those choices are fixed.

Repeatedly choosing models from test results makes the test set part of development. It can then give an optimistic estimate of performance. The validation set serves that development role so that a separate test can remain a final assessment.

The split should match the intended use. To predict later dates, hold out later observations. To predict on new fields or people, keep the relevant groups separate. A random row split may be inappropriate when related records appear in both sets.

The illustration assigns 30 of 50 observations to training, 10 to validation and 10 to testing: a 60/20/20 split. The block widths and dot counts show the same proportions. Training commonly receives the largest share, but there is no mandatory ratio; the split should leave enough evidence for fitting, model selection and a meaningful final evaluation.

Training set: fit adjustable model settings and input transformations.Validation set: compare choices such as model complexity.Test set: assess the final selected procedure.Hold out later dates or different groups when those match the intended use.

3.6Fit the training points; compare unseen validation points

Choose a polynomial degree and noise level. The model is fitted using 16 training points; its validation score uses 40 separate points generated from the same synthetic process. The true (generating) curve is the known rule used by this simulator: y = 2 + 1.2x − 0.9x². Each dot is a value on that curve plus random noise. Choose Show true curve to reveal it. The fitted curve is instead learned from the training dots; the fitting method is not given the true rule. We can reveal that rule here because the data are artificial; with real data it is usually unknown.

Compare training and validation errors as degree increases. A more flexible family can lower training error while failing to improve, or worsening, validation error. This is the overfitting pattern: fitting details of the sample that do not transfer to new observations. A degree-9 polynomial has more flexibility than degree 2, but need not pass through all 16 training points.

Noise is random variation added to the generated targets. The seed makes a chosen dataset repeatable. Because you use validation results to compare degrees, those points are a development resource, not a final untouched test set. A later test would assess the selected procedure on further held-out observations.

The control σ (sigma) is the standard deviation of the added noise: a larger value produces more variation around the generating curve. Keeping the same seed repeats the sample so that model comparisons can use the same observations.

3.7Data leakage lets evaluation information enter preparation

Data leakage occurs when information unavailable in the intended prediction setting influences model development or evaluation. It can enter through input construction, preprocessing or a split that mixes related cases.

For example, computing feature means from all observations before splitting lets held-out inputs influence preprocessing, even if their target labels are never used. Estimate such preprocessing from the training data, then apply the fitted transformation to validation and test inputs.

Also inspect time and group relationships. If the goal is to predict future months for new fields, evaluation should hold out later dates and relevant fields. Merely hiding individual rows can leave closely related records available during training. Decide the deployment question before choosing the split.

Preprocessing transforms the inputs before fitting or prediction, such as subtracting a feature mean learned from data. Fit these learned quantities on training observations only and apply the same transformation to held-out observations.

Preprocessing transforms inputs before prediction, for example by subtracting a learned mean. Fit that transformation on training data, then apply it unchanged to held-out inputs.

3.9Reason from the definition, then apply it

With 80 observations and four predictor columns, the design matrix has shape 80 × 4 and the target vector has 80 entries. The lookup ID is not an input merely because it is stored alongside the measurements.

Both (1,0,0) and (2,−1,0.5) belong to Θ = ℝ³. Fitting a negative coefficient changes the parameter setting without changing the allowed space or quadratic form.

In the toy yield case the residual is observed minus predicted: 4 − 6 = −2 kg. A negative residual means overprediction. Its square is 4 kg², illustrating why mean squared error has squared target units.

For future months and unseen fields, the held-out data should be later in time and contain different field identities. A row shuffle alone does not enforce either requirement.

3.10A complete prediction problem follows this chain

A prediction problem begins with an observation unit, available predictors and an outcome. A dataset records input–target pairs; a matrix and vector organize their values. A model family and allowed parameter space then specify the candidate prediction rules.

Training fits a parameter setting. Validation compares development choices, and a held-out test assesses the selected procedure for the intended future use. The next regression lecture develops specific fitting methods within this framework.
