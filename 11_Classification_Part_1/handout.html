People commonly organize information into categories. Classification asks how a machine learning model can learn those categories from examples and assign a label to a new observation. 5.1 · From the observations to a modelWhy not fit a line or polynomial?

Fit the same 100 patients with different polynomial degrees.
Ordinary regression can leave the range [0,1], so its outputs are not automatically valid class probabilities.

The observations occupy two levels because the outcome is either zero or one. In this particular teaching sample, the transition between those levels is sharp. A familiar first attempt is to fit a regression line or polynomial to the numerical codes and then round or threshold its output. The purple line is an actual ordinary-least-squares fit to the same one hundred observations. It gives some predictions below zero and above one, so those values cannot be interpreted directly as probabilities. A higher-order polynomial can follow a steep pattern more closely, but it does not automatically enforce valid probabilities either. Regression on binary labels is possible; the point is that we want an explicit, interpretable model of the probabilities of the classes. We will therefore estimate P(Y=0|X=x) and P(Y=1|X=x), and subsequently turn those estimates into a label. This motivates the probabilistic framework introduced after the formal description of the classification task.

Select several polynomial degrees to overlay their fits on the same observations. A higher degree allows more bends and usually fits these training labels more closely, but it does not constrain predictions to [0,1]. The shaded regions mark values that cannot be class probabilities. The purpose is to motivate a probability model rather than to choose the best degree from training fit.

In predictors, uncertainty is related to the quality of the measurements. In outcomes it can also arise because relevant predictors were not collected. Epistemic:

Uncertainty in the measurements that can be controlled, to a certain extent.

Better tools or additional predictors can decrease epistemic uncertainty.

Aleatoric:

Uncertainty intrinsic in the process that cannot be controlled and therefore not decreased.

We can know these probabilities and still be uncertain about the next outcome.

The distinction depends on the context and on what we measure.

Epistemic: uncertainty in the measurements that can be controlled, to a certain extent. In a predictor, we can adopt more accurate measurement tools. In an outcome, we can also include more predictors. Epistemic uncertainty can be decreased.

Aleatoric: uncertainty intrinsic in the process that cannot be controlled and therefore not decreased. The distinction is labile and depends on the context in which we conduct experiments. What can be controlled depends on the measurement setup and available inputs.

The left plot illustrates more precise measurements through a narrower spread of readings. The right plot describes a fair die within a fixed probabilistic model: each face has probability 1/6, and we are still uncertain about the next outcome.

During data collection, we may record a variable such as human hair colour. In a population where black hair is more common than red hair, a varied sample will generally contain more black-haired people. The example illustrates that possible values need not occur equally often.

Some data occur more often than others, and this is important to account for in our analyses. A probability model associates different probabilities with values that occur at different frequencies, rather than treating all possible outcomes as equally common.

ℙ(Y=yi∣X=xi)=p(yi∣xi)

Read: “The probability that the outcome is yᵢ, given input xᵢ.” Both expressions give that same probability.

Known input: condition on this value

X=xi=0.50

Hypothetical patient input

Possible outcomes under that condition

0: 30%1: 70%
p(0∣xi)=0.30,p(1∣xi)=0.70

Illustrative probabilities for this same input.

Lowercase p names the conditional probability mass function (PMF) of Y given X.
Because Y has discrete class labels, this function assigns a probability to each possible class.
For example, p(1 | 0.50) = 0.70. The event notation ℙ(Y=1 | X=0.50) gives the same probability.
ℙ = probability operator, applied to an eventp(yᵢ | xᵢ) = the PMF evaluated at these valuesX,Y = random input and outcomexᵢ,yᵢ = recorded values for case i𝒴 = {0,1}, the class setPMF values sum to 1 at each input.

A categorical outcome can be uncertain: observers can disagree about the colour of a cloth, or recorded predictors may not fully determine a disease label. A classification algorithm therefore often estimates the conditional probability of each class given the input.

Lowercase p names a conditional probability mass function (PMF): for a fixed input, it assigns a probability to each possible class of the discrete outcome Y. Here “mass” means probability assigned to a discrete class. The input X can itself be continuous.

The full function name is pY∣X. Its value at class y and input x is:

pY∣X(y∣x)=ℙ(Y=y∣X=x)=p(y∣x)

ℙ is a probability operator applied to the stated event. The lowercase p is the name of the function whose value gives that probability. We shorten the full function notation to p(y | x) when the variables are clear. For any fixed input, the probabilities assigned to the possible classes sum to one.

For instance, p(1 | xᵢ)=0.70 means ℙ(Y=1 | X=xᵢ)=0.70. At this same input, p(0 | xᵢ)=0.30. These are hypothetical probabilities, not clinical estimates. They describe possible outcomes for the given input, and they add up to one.

Capital X and Y denote random variables. Lowercase xᵢ and yᵢ denote values recorded for case i. The class set 𝒴 is different from the outcome variable Y. In this hospital task, 𝒴={0,1}. Later, subscripts such as pY or pX∣Y identify which variables a distribution describes. Those subscripts identify the variables and conditioning of the probability function.

5.2.1 · Why use class probabilities?Why predict probabilities before choosing a class?

1. A smoother learning signal

0.60 ⟶ 0.80

Probabilities change continuously. Often, optimizing them is simpler than optimizing discrete class labels.

If the observed class is 1, 0.60 to 0.80 strengthens the prediction while its label stays 1.

2. A measure of model confidence

Concentrated probabilities express more confidence. Similar probabilities express less.
A confident prediction can still be wrong.

Estimating class probabilities offers two advantages. Often, optimizing a model over continuous probabilities is simpler than optimizing it over discrete class labels. A small change in the model can change a probability even when the most likely label stays the same.

The distribution also expresses the model’s confidence. A peaked distribution, such as (0.05,0.95), puts most probability on one class. A flat distribution, such as (0.50,0.50), gives little preference to either class. In a multiclass problem a flat distribution spreads probability approximately evenly among all classes. A confident prediction can still be wrong.

5.3 · Optimal Bayes classifierIf we knew the true probabilities, which label should we choose?

The Optimal Bayes Classifier (OBC) chooses the most probable class. It is a theoretical benchmark: in practice we usually have to estimate those probabilities.

y^i=f(xi)={1if ℙ(Y=1∣X=xi)≥0.50otherwise

Example: 70% present, 30% absent

Choose class 1.
It is the label with the higher chance of being right.

What does “optimal” mean here?

The lowest expected fraction of wrong labels, using these features and treating every mistake as equally costly.

𝒴 = {0,1}, the class setxᵢ = input for observation iŷᵢ = predicted labelf = Optimal Bayes ClassifierAt exactly 50%, either label has the same expected error. This rule chooses 1.

The Optimal Bayes Classifier (OBC) assumes that we already know the true relationship ℙ(Y | X). Usually this relationship is unknown. The OBC is therefore a theoretical baseline standard, rather than a training procedure.

For two classes, the rule predicts 1 when ℙ(Y=1 | X=xᵢ)≥0.5, and predicts 0 otherwise. It chooses the label associated with the greater probability. At a tie both labels have the same error probability, and the displayed rule chooses 1. Optimality concerns the expected fraction of wrong labels, counting each mistake equally.

5.3 · Measuring classification mistakesThe error rate is the probability that our label is wrong

Even the most likely class can be wrong. To compare classifiers, we average their mistakes over possible inputs and outcomes.

R(f)=𝔼XY[𝟙(Y≠f(X))]

𝟙 is called an indicator function

𝟙(Y≠f(X))={1wrong label0correct label

The expectation averages those 0s and 1s

Toy population: 10 equally likely cases

0100100010
R(f)=3 wrong10 cases=0.30

0 = correct label1 = wrong label

R(f) is called risk or expected classification error. It lies between 0 and 1.
We will show that the Bayes rule gives the smallest possible R(f) for these features.
f = any classifierf(X) = predicted labelY = outcomeX = input𝟙(…) = 1 when the condition is true, otherwise 0𝔼ₓᵧ = average over X and Y

Risk here means expected classification error under 0–1 loss. It is not an unspecified measure of harm. For each possible observation, the indicator contributes one if the prediction differs from the outcome and zero otherwise. The average of this zero-or-one variable is the probability of an error. The expectation averages with respect to the population distribution of both X and Y, so common observations receive greater weight than rare ones. Exact population risk is usually unknown. The fraction of wrong predictions in representative held-out observations estimates it. The following two sections first compare the two possible predictions at one fixed input and then prove that making the better choice at every input minimizes the population average.

The example uses a toy population of ten equally likely possible cases. Each contributes an indicator: one for an error, zero for a correct prediction. Three of the ten cases have an error, so the expectation of the indicator is 3/10=0.30. For a finite evaluation sample rather than the full population, the same average would estimate the unknown population risk.

5.3 · Why the optimal Bayes classifier worksWhich class gives the smaller chance of a mistake?

Reminder: the OBC chooses the class with the highest true probability. The individual case’s label is still unknown.

Return to two classes, {0,1}. Hold one input x fixed and compare the two possible predictions.

p(x)=p(1∣x)=ℙ(Y=1∣X=x)

Here p(x) always means the probability of class 1. The class 1 is understood in this shorter notation.

Example at this input: suppose p(x) = 0.70.

Class 0: 30%Class 1: 70%

If we predict 0

We make a mistake when the actual class is 1.

Error probability=p(x)=0.70

If we predict 1

We make a mistake when the actual class is 0.

Error probability=1−p(x)=0.30
The OBC therefore predicts class 1 here.
Its chance of a mistake is 30%, the smaller of the two.
y^=argmaxc∈𝒴 ℙ(Y=c∣X=x)
X = random input, x = one fixed input valueY = actual class, 𝒴 = {0,1} = possible class labelsŷ = predicted label, c = candidate class from 𝒴p(X) = the same class-1 probability function evaluated at the random input X

We return to a binary problem with class labels {0,1}. Fix one particular input x. We compare two decisions for that same input: predicting 0 and predicting 1.

On these proof slides, p(x) is shorthand for p(1 | x)=ℙ(Y=1 | X=x). The class 1 is already fixed in its definition, so it is left out of the arguments. The other class has probability 1−p(x), because the two possible class probabilities add up to one.

Suppose p(x)=0.70. Class 1 then has probability 70%, and class 0 has probability 30%. If we predict 0, we are wrong whenever the outcome is 1: a 70% chance of a mistake. If we predict 1, we are wrong whenever the outcome is 0: a 30% chance. We choose 1 because 30% is smaller than 70%. These are probabilities, so an individual prediction can still be wrong.

More generally, predicting 0 has error probability p(x), and predicting 1 has error probability 1−p(x). Choose the smaller of these two errors at each input. Minimizing the error separately at every input also minimizes their overall average, which the following section derives.

Lowercase x is a fixed input value, so p(x) is a number for that input. Uppercase X is a random input, so p(X) varies with whichever input occurs. Once X=x is observed, p(X) takes the value p(x). The next derivation uses p(X) while averaging over inputs. In both forms p still denotes the class-1 probability, rather than the input density pX(x) introduced later.

The Optimal Bayes Classifier chooses the class with the greatest true conditional probability for the input. Its argmax rule returns a class label. It uses the true probability distribution as a theoretical benchmark, while the true label of an individual new observation remains unknown when making the prediction.

5.3 · Interactive derivationWhy does the Bayes rule minimize the error rate?

We prove the two-class case. Let p(X)=ℙ(Y=1∣X).

p(X) = probability that Y = 1 given Xf = the classifier being chosenR(f) = expected classification error𝔼 = average over the indicated variables𝔼ᵧ|ₓ = average over labels with input fixed𝟙(A) = 1 if A is true, otherwise 0X,Y = random input and outcomex = one particular input value

Step 1. Start from the error rate

R(f)=𝔼XY[𝟙(Y≠f(X))]

We want to measure how often the classifier gives a wrong label.

For each possible case, the indicator records 1 for a mistake and 0 for a correct prediction.

The expectation averages these results over the population. For example, R(f) = 0.30 means a 30% chance of a mistake.

Step 2. Average in two stages

=𝔼X[𝔼Y∣X[𝟙(Y≠f(X))]]

We calculate the same average in two stages.

First fix an input X and average over the labels Y that can occur there. Then average those results over inputs, weighting them by how often they occur.

Fubini’s theorem allows this rewriting (a double integral can be calculated one variable at a time, and either order gives the same result). The overall error rate has not changed.

Step 3. Write the two possible mistakes

=𝔼X[p(X)𝟙(f(X)=0)+(1−p(X))𝟙(f(X)=1)]

We now write out the two ways the classifier can make a mistake.

If it predicts 0, it is wrong when Y = 1, with probability p(X). If it predicts 1, it is wrong when Y = 0, with probability 1−p(X).

Exactly one indicator is 1. It selects the term for the label f actually predicts.

Example: if p(X) = 0.70 and f predicts 1, the first term is 0 and the second is 0.30.

Step 4. Choose the smaller error at each input

p(x)𝟙(f(x)=0)+(1−p(x))𝟙(f(x)=1)

Fix one particular input x and compare the two possible decisions.

Predicting 0 has error probability p(x). Predicting 1 has error probability 1−p(x).

Choose the smaller of these two errors. Doing this at every input also makes their overall average as small as possible.

Step 5. Recover the Optimal Bayes Classifier

f(x)={1if 1−p(x)≤p(x)0otherwise={1if p(x)≥0.50otherwise

Choose class 1 when its error, 1−p(x), is no larger than the error of choosing class 0, p(x).

Adding p(x) to both sides gives 1 ≤ 2p(x), so p(x) ≥ 0.5. Otherwise choose class 0.

This is the Optimal Bayes Classifier: the best decision at each input gives the lowest overall expected error.

5.3 · Limits of predictionOptimal does not mean error-free

For 100 comparable cases with p(x) = 0.7, always predicting 1 gives about 30 mistakes on average.
Without additional information, no decision rule can improve that expected error.
p(x) = ℙ(Y=1 | X=x)The 100 cases illustrate expected proportions, not an exact guarantee.

The OBC can make errors even when it knows the true probabilities. With p(x)=0.7, choosing class 1 has probability 0.3 of being wrong. Across 100 comparable cases that gives 30 mistakes on average. Naive Bayes uses Bayes’ theorem to estimate the posterior probability of a class given the observed input. The word equation and the symbolic equation express the same calculation: multiply likelihood by prior, then divide by evidence.

The subscript on p identifies the distribution. pY(y) describes the class variable Y. pX(x) describes the input X. pX∣Y(x | y) describes inputs within a fixed class, and pY∣X(y | x) describes classes after the input is known. Because the class variable is discrete, pY∣X(y | x)=ℙ(Y=y | X=x). The earlier shorthand p(y | x) means the same thing.

For a continuous input, pX and pX∣Y are probability densities. A density describes how probability is distributed over input values. Its value at one point is not the probability of observing that exact value. Bayes’ theorem still produces a class probability through the ratio. To use the rule, we must estimate the likelihood, prior and evidence, or show which terms can be omitted for class selection.

In the weather example, X records cloud condition and Y records rain status. The posterior is the probability of rain given that it is cloudy. The likelihood reverses the conditioning: probability of cloudy skies given rain. The prior is the overall probability of rain before considering the cloud condition. The evidence is the overall probability of cloudy skies, across rainy and dry cases.

5.5 · Estimating the distributionsWhy can we use log scores and omit the evidence?

01 · Start from the Bayes decision

y^=argmaxc∈𝒴 pX∣Y(x∣c)pY(c)pX(x)

For one fixed input x, compute a posterior score for every possible class c.

The numerator is likelihood × prior. The denominator is the evidence.

argmax returns the class label with the largest value, not that value itself.

02 · Apply a logarithm

y^=argmaxc∈𝒴 log(pX∣Y(x∣c)pY(c)pX(x))

For positive values, log is strictly increasing: if a > b, then log(a) > log(b).

It preserves the order of the class scores, so the winning class does not change.

We can therefore compare logarithms instead of the original ratios.

03 · Expand the logarithm

y^=argmaxc∈𝒴 [log(pX∣Y(x∣c))+log(pY(c))−log(pX(x))]

Use log(ab/d) = log(a) + log(b) − log(d).

Multiplication in the numerator becomes addition. Division by the evidence becomes subtraction.

Nothing has been dropped: this is exactly the preceding score, written as three terms.

04 · Remove the common evidence

y^=argmaxc∈𝒴 [log(pX∣Y(x∣c))+log(pY(c))]

For this fixed input x, the negative log evidence is the same number for every class c.

Removing the same number from all class scores cannot change their order.

We therefore need the likelihood and prior to select a class, but not the evidence.

5.6 · Logistic regressionCan we predict the class probability directly?

Naive Bayes

First model the feature values within each class.

Estimate how the features are distributed for each class c and how common that class is (its prior).

Then use Bayes’ theorem to compute the probability of class c for the observed input xᵢ:

pY∣X(c∣xi)=pX∣Y(xi∣c)pY(c)pX(xi)

This combines the feature likelihood, class prior and evidence.

Logistic regression

Model the probability of a class directly from the feature values.

For input xᵢ, calculate a weighted sum of its features: a linear score.

An S-shaped logistic function converts that score into a probability between 0 and 1:

ℙ(Y=1∣X=xi)=σ(xi)

The coefficients are learned from labelled examples. The following section gives the formula for σ(xᵢ).

X = input features, xᵢ = their values for observation iY = class variable, c = a candidate class labelσ(xᵢ) = logistic model’s probability of class 1p = probability or density function identified by its subscript

Logistic regression is closely related to regression models, although it is most often used for classification. Here we consider binary classification. Instead of first estimating feature distributions within each class, we choose a formula directly for ℙ(Y=1 | X=xᵢ).

A familiar linear combination of the inputs can take any real value. The logistic function transforms this score into a value between zero and one, which can represent the probability of class 1.

In the Naive Bayes formula, pX∣Y(xi∣c) describes the distribution of the input features within class c, while pY∣X(c∣xi) describes the probability of class c after the input xᵢ is known. Bayes’ theorem relates the two conditional distributions. Logistic regression chooses a parametric formula for the class probability directly. Here σ(xᵢ) includes both the linear score and its logistic transformation, as written in the following section.

Why multiply? We want the probability of both recorded labels occurring together. Given the inputs, the model treats the two patients’ labels as independent, so it multiplies the probability it assigns to each recorded label.

For model A the product is 0.9×0.1=0.09. For model B it is 0.6×0.6=0.36. Model B assigns four times as much likelihood to the observed pair, even though model A is more confident about its second, incorrect label. This is a concrete example of the two-product MLE formula.

Maximum Likelihood Estimation (MLE) chooses coefficients that maximize the likelihood of the observed data. Inputs and labels stay fixed while we compare candidate coefficient vectors 𝛃=(β₀,…,βₘ). The vector belongs to ℝᵐ⁺¹ because it contains m feature coefficients and an intercept.

For each observation with yᵢ=1, the probability assigned to the observed label is σ(xᵢ). For each observation with yᵢ′=0, that probability is 1−σ(xᵢ′). The two products include the two label groups, with i and i′ serving as observation indices. Assuming independent observations under the model, multiply all their contributions.

The factors depend on 𝛃 through the logistic function. Maximizing the product encourages σ(xᵢ) toward 1 for positive labels and toward 0 for negative labels. We write argmax because the output 𝛃^ is a vector of coefficients, not the maximum likelihood value itself.

5.6.1 · Maximum likelihood estimationHow do we find those coefficients?

1. Try coefficients

Start with a candidate 𝛃.
Use the logistic formula to compute σ(xᵢ) for every training input.

2. Calculate the likelihood

For each label 1 use σ(xᵢ).
For each label 0 use 1−σ(xᵢ).
Multiply those contributions.

3. Improve the candidate

A numerical optimizer adjusts the coefficients to seek a larger likelihood.
Repeat until its stopping criterion is met.

This problem has no closed-form coefficient formula like ordinary least squares.
We use numerical optimization: improve candidate coefficients through calculations.
𝛃 = coefficients currently being triedσ(xᵢ) = probability computed from those coefficients𝛃^ = resulting fitted coefficientsNumerical optimization = repeated calculations to improve candidate coefficients

The likelihood objective tells us which coefficients we want, but it does not provide a closed-form solution. Unlike the ordinary least-squares formula seen in regression, logistic regression generally requires numerical optimization.

Conceptually, try a coefficient vector, compute the class probabilities and their likelihood, then adjust the vector to seek a larger likelihood. A numerical routine repeats calculations until its stopping rule is met. This description explains the role of the optimizer without introducing a separate optimization algorithm.

5.6.1 · Maximum likelihood estimationTry coefficients and read the likelihood

The inputs and labels stay fixed. Select a patient, read the probability assigned to their observed label, then see how all 100 contributions combine.

This example uses the same 100 hospital teaching observations as Part 1. Each input xᵢ is a cholesterol-related measurement on an illustrative scale. The recorded label yᵢ is 0 for disease absent and 1 for disease present. Neither the measurements nor the labels change when the coefficients change.

The controls try candidate intercepts β₀ and slopes β₁. For a selected patient i, calculate the score β₀+β₁xᵢ and pass it through the logistic formula to obtain σ(xᵢ). This is the model’s probability of class 1, not the patient’s recorded label.

The contribution to likelihood depends on the label that was actually recorded. If yᵢ=1, use σ(xᵢ). If yᵢ=0, use 1−σ(xᵢ). Multiplying these contributions across all 100 independent observations gives the likelihood of the observed labels under those candidate coefficients.

The default candidate is β₀=−7.5 and β₁=15.5. The first recorded input is approximately 0.5488 and has label 1. Its score is about 1.0066 and its class-1 probability about 0.7324, so this observation contributes about 0.7324 to the product. Other patients supply the remaining factors. Displayed numbers are rounded, while the calculation uses full precision.

Choose a flat, reversed or steeper candidate, or adjust the coefficients yourself. A numerical fitting routine would seek coefficients with a larger joint likelihood. This explorer makes the objective visible and lets you compare candidates manually. It does not claim to run a fitting algorithm or to have found a finite maximizer.
