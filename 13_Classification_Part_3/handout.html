6 · ClassificationHow can we classify by location?

In Part 2, we used nearby examples to classify a new point. Now we’ll focus on the geometry of the decision. What separates the parts of the plot that get different labels?

A separator, also called a discriminant, is a decision rule that divides the input space into regions. A new point gets the label of the region it lands in. With C classes, there are C prediction regions, one for each label. For two classes, a straight line can serve as the boundary if the classes lie on opposite sides.

Can one line separate the two classes in a plot of switch settings? We’ll start with logical AND, set a rule by hand, then see how a perceptron can learn one from examples. Later, we’ll try the same idea on XOR to see where a single straight boundary falls short.

6.1 · McCulloch & Pitts NeuronHow can a threshold neuron model AND?

For each switch setting xᵢ, the neuron adds the two inputs. The sum g(xi) counts how many switches are on. The neuron predicts 1 when the score reaches the threshold b, and 0 otherwise. To model AND, only the setting (1, 1) should reach b.

g(xi)=∑j=1mxij
y^i={1if g(xi)≥b0otherwise=1(∑j=1mxij−b≥0)
i = observation indexj = feature index (1 to m)xᵢ = input vector for observation ixᵢⱼ = feature j of observation im = number of input featuresg(xᵢ) = sum of the inputs for observation ib = threshold (called bias in this neuron)ŷᵢ = predicted class

The McCulloch & Pitts neuron is a simplified model of a firing neuron. In the plot, (1, 0) and (0, 1) each give a score of 1, and (1, 1) gives a score of 2. The designer sets b by hand. The indicator returns 1 when its condition holds, including equality at b. On the next slide we plug the switch settings into both formulas and compare two thresholds.

Keep class 0 below the threshold

The largest class-0 sum is 1. A threshold of 1 would also fire for a single active input.

Let class 1 reach the threshold

1+1≥b⟹b≤2

The only class-1 row has sum 2. A threshold of 2 still fires at equality.

Combine the two bounds

1<b≤2⟺b∈(1,2]

This interval contains every threshold that classifies all four AND inputs correctly.

X₁ and X₂ = binary inputsY = AND outputb = threshold

Class 0 requires its sum to be strictly below b because the neuron fires at equality. The three class-0 rows therefore give 0 < b, 1 < b and 1 < b. Class 1 requires 2 ≥ b. Combining them gives 1 < b ≤ 2. For example, b = 1.9 satisfies both bounds.

In 1958, Frank Rosenblatt asked how memory changes what we recognize.

“In what form is information stored, or remembered?”

A trainer corrected the machine when it guessed wrong. We’ll do the same with the weights of a separator.

The Navy’s photo caption reported perfect recognition in the typeface used for training and 85% after letters in another typeface were added. That is an early example of a generalization question. If the shape of the letters changes, will the same learned weights still work?

6.2 · PerceptronThe perceptron learns a weighted threshold rule

To separate the noisy classes, the perceptron uses a weighted McCulloch & Pitts neuron (MPN). It learns the weights w = (w₀, …, wₘ) from labeled examples, so some inputs can have more influence than others.

y^i= 𝟙 ( ∑j=0m wjxij ≥0) = 𝟙 ( ∑j=1m wjxij+w0 ≥0)

Why are the forms equal? The sum starting at j = 0 includes the term w₀xᵢ₀. Since xᵢ₀ = 1 for every observation, that term is just w₀. The second form writes it outside the sum.
Setting every feature weight to 1 and w₀ = −b gives the original MPN rule with threshold b.

wⱼ = weight for feature j, w₀ = biasxᵢⱼ = feature j of observation ixᵢ₀ = 1 for every observationm = number of input featuresŷᵢ = predicted class (0 or 1)𝟙 = indicator function

A perceptron is a threshold neuron with learnable weights and bias. A positive weight raises the score as its feature increases, and a negative weight lowers it. In two dimensions the score-zero line separates the predicted classes. Learning the weights lets the model change the line’s direction, and the bias shifts its position. Writing the constant input xᵢ₀ = 1 lets us use the same update rule for the bias and the other weights.

6.2 · PerceptronUse the prediction error to update the weights

The update is inspired by Hebbian learning, a principle that links connection strength to neuron activity. The perceptron uses the known label to decide how to correct its prediction.

wj(t+1)=wj(t)+(yi−y^i)xij(j=0,…,m)
Observed labelPredicted labelChange to each weight
00Keep the weights
11Keep the weights
10Add each input component
01Subtract each input component
yᵢ = observed class, ŷᵢ = predicted classxᵢⱼ = feature j of observation it = current step, t + 1 = next stepj = weight index, including j = 0 for the bias

For each observation, compute the prediction with the current weights, then use that prediction error to update each weight. The same rule applies to the bias because xᵢ₀ = 1. The index t counts the observations processed during training.

6.2 · PerceptronWhen has the perceptron finished learning?

Apply the update rule to each observation in turn. After one pass through the training set, start another pass with the latest weights.

When convergence is guaranteed

If the training classes are linearly separable, the perceptron finds a separator after finitely many updates. With two features, a straight line can separate the classes.

How to tell it has converged

Check for one complete pass with no mistakes. Every weight stays the same throughout that pass, so the same rule correctly classifies every training example.

Here convergence means that a full pass makes no updates. A single correct prediction also leaves the weights unchanged for that step. To check convergence, continue through every observation. The finite-update guarantee applies to the standard perceptron on a finite, linearly separable training set. The lab caps the number of passes so that runs on XOR can end.

6.2 · PerceptronWhy does the correction move the score?

Compare the weighted score for the same example before and after one update. Zero or more predicts class 1. A negative score predicts class 0.

Correct prediction

yi=y^i⟹wj(t+1)=wj(t)

The predicted class matches the observed class, so yᵢ − ŷᵢ = 0. The update adds 0 to every weight, leaving the score for this example unchanged.

Missed a class 1

∑j=0mwj(t+1)xij=∑j=0m(wj(t)+xij)xij

The true class is 1 and the prediction is 0. Put the error 1 − 0 into the update rule for one weight.

wj(t+1)=wj(t)+(1−0)xij=wj(t)+xij

In the right sum, the xᵢⱼ inside the parentheses comes from this weight update. The xᵢⱼ outside is the input we multiply by to score the same example again.

Expand the product

∑j=0mwj(t+1)xij=∑j=0m(wj(t)xij+xij2)

In the right-hand sum, multiply the outside xᵢⱼ by both terms in parentheses. The old weight gives wⱼ⁽ᵗ⁾xᵢⱼ. The added input gives xᵢⱼ × xᵢⱼ = xᵢⱼ².

Separate the sums

∑j=0mwj(t+1)xij=∑j=0mwj(t)xij+∑j=0mxij2

Collect the old weighted inputs into the first sum. That is the old score. The second sum adds the squared inputs. This increases the score because xᵢ₀ = 1 contributes 1². The prediction becomes 1 when the new score reaches zero or above.

Predicted 1 by mistake

∑j=0mwj(t+1)xij=∑j=0mwj(t)xij−∑j=0mxij2

Now the true class is 0 and the prediction is 1, so the error is −1. Each new weight is the old weight minus its input. The same multiplication gives old score minus the sum of squared inputs. A negative new score predicts class 0.

yᵢ = observed class, ŷᵢ = predicted classxᵢⱼ = feature j of observation ixᵢ₀ = 1wⱼ⁽ᵗ⁾ and wⱼ⁽ᵗ⁺¹⁾ = weight before and after the updatet = current update stepm = number of input features

Read steps 2–4 as three lines of the same calculation for a missed class 1. Step 5 switches to the opposite mistake. Each correction moves the score of that example toward the right class. For example, if a missed class 1 starts at −3 and the sum of squared inputs is 2, the score rises to −1 and still predicts 0.

6.2.1 · Learning rateThe learning rate controls the size of a correction

wj(t+1)=wj(t)+η(yi−y^i)xijη>0

One mistake

Doubling η doubles the size of that weight correction.

A complete run

With zero initial weights, fixed order and constant positive η, the weights scale with η and the mistake sequence stays the same in exact arithmetic.

η = positive learning rateyᵢ = observed class, ŷᵢ = predicted classxᵢⱼ = feature j of observation iwⱼ⁽ᵗ⁾ = weight before this update

A learning rate sets the update scale. Try 0.25, 1 and 4 in the training lab. In this classic zero-initialized setup, the sign of each score is unchanged by positive rescaling, so the number of mistakes is unchanged. Effects on speed and numerical stability depend on the setup. The basic rule uses η = 1.

6.2.2 · What’s nextTry to separate the four XOR points

Change AND to “exactly one switch is on.” Can you draw a single line that separates the two labels?

XOR outputs 1 when exactly one input equals 1. The class-0 points are (0,0) and (1,1), and the class-1 points are (1,0) and (0,1). Both classes have the same midpoint (½,½). A single straight separator cannot put their line segments on opposite sides. Try XOR in the perceptron lab to see the updates continue.

6.2.2 · What’s nextWhy one line cannot separate XOR

Class 0 at (0,0) and (1,1)

w0<0
w1+w2+w0<0

Class 1 at (1,0) and (0,1)

w1+w0≥0
w2+w0≥0

w1+w2+w0≥−w0>0
wⱼ = weight for feature j, w₀ = biasOutput 1 at a score of zero or aboveOutput 0 at a negative score

Adding the two class-1 inequalities gives w₁ + w₂ + 2w₀ ≥ 0. Since the score at (0,0) requires w₀ < 0, this implies a positive score at (1,1), contradicting its class-0 label. The two classes occupy opposite corners. A multilayer perceptron can solve XOR, as can a suitable nonlinear representation.

6.2.2 · What’s nextFour points, one line, and a famous book

Marvin Minsky and Seymour Papert’s 1969 book Perceptrons studied the limits of this kind of classifier. XOR is the smallest parity example. It asks whether the number of active inputs is odd.

What made it worth studying

“worthy of study despite (and even because of!) its severe limitations”

We just saw one such limit. A straight line through the two original features cannot separate XOR.

What they left open

“elucidate (or reject) our intuitive judgment that the extension is sterile”

They were skeptical that adding layers would yield a useful learning rule. Their wording invites a test of that conjecture.

Minsky & Papert, Perceptrons (1969) · §13.2, pp. 231–232

The book’s analysis covered more than XOR, including parity and connectedness under restrictions on the units. The two-input example gives us a concrete way to see why the choice of features matters. A new intermediate feature can change which labels a straight line can separate.

6.2.2 · What’s nextWhat cooled during the first AI winter?

The first AI winter was a period of reduced interest and funding for parts of AI research. The perceptron debate was one part of a broader slowdown.

1960s · Funding was already tightening

Rosenblatt struggled to secure funding for larger projects before the 1969 book appeared.

1973 · The UK scrutinized AI

James Lighthill’s review asked why methods that worked on small examples struggled as the number of possibilities exploded.

1986 · XOR returned as a test case

Rumelhart, Hinton and Williams showed how backpropagation could train hidden units that let a network solve XOR.

In Part 4, we’ll ask what happens when a classifier gets a different set of features to work with.

Funding history · Lighthill’s report · The 1986 XOR experiments

Lighthill’s report discussed a broader concern familiar from the search lectures. Adding more possibilities can make a small working demonstration very expensive at a realistic scale. Meanwhile, researchers kept working on neural networks. To see what a hidden unit changes, give the XOR classifier one extra feature that turns on when both inputs are 1. Add the two input values and subtract twice that feature. The result is 1 for the two cases with exactly one active input and 0 for the other two. This is a concrete feature the output can use to separate the classes.
